# 在线平台演进路线

## 目标架构

保留一套稽核规则、整改流程、专题分析和报表逻辑，通过适配层支持两种运行形态：

| 能力 | 本地模式 | 在线模式 |
| --- | --- | --- |
| 数据库 | SQLite | PostgreSQL |
| 文件 | 本机工作目录 | 服务端对象存储 |
| 身份 | 单机使用者 | 登录、组织、角色与数据权限 |
| 并发 | 单进程工作区锁 | 数据库事务、任务锁和幂等控制 |
| 交付 | Windows/macOS 可执行程序 | HTTPS 服务与持续部署 |

## 阶段一：运行边界

- [x] 默认运行模式明确为 `local`。
- [x] 无效运行模式启动失败。
- [x] 在线依赖未完成时，`APP_MODE=online` 明确拒绝启动。
- [x] 抽取数据库接口，业务流程通过仓储和数据库管理适配器访问 SQLite。
- [x] 抽取文件存储接口，以文件引用衔接上传、生成、发布和清理流程。

## 阶段二：多用户在线基础

- [x] PostgreSQL 迁移、连接池和事务边界。
- [x] 文件上传、下载、校验及 S3 兼容对象存储。
- [x] 用户、组织、角色和批次数据范围权限。
- [x] 服务端会话、CSRF、账号锁定和安全响应头。
- [x] 操作日志包含操作者、组织、请求来源和关联任务。
- [x] 长耗时导入、稽核、分析和导出进入持久化后台任务。

## 阶段三：部署与迁移

- [x] 本地 SQLite 与在线 PostgreSQL/MinIO 双测试矩阵。
- [x] SQLite 数据迁移计数校验、事务回滚及演练工具。
- [x] 备份恢复脚本、就绪探针和请求审计留存。
- [ ] 灰度环境验收后开放生产环境。
- [x] 本地版继续可独立运行和打包。

## 阶段四：手机端

先提供响应式 Web/PWA，优先覆盖问题查看、整改填报、复核、进度和消息提醒。
只有明确需要系统推送、拍照扫码、深度离线或设备能力时，再建立原生或跨平台 App。
手机端只复用在线 API，不复制稽核与工作流逻辑。

## 当前配置契约

源码与桌面程序默认保持本地模式：

```bash
APP_MODE=local scripts/start.sh
```

在线基础组件现已具备启动条件。生产环境必须通过 HTTPS 入口提供服务，并设置 PostgreSQL、
对象存储和高强度引导管理员密码；首次登录后应立即创建正式组织账号并轮换引导密码。
